# Módulo 3: Detección de Incidentes y Respuesta

## Descripción

En este módulo se estudian los procesos y herramientas utilizados para detectar, investigar y responder a incidentes de ciberseguridad. Se profundiza en técnicas como la caza de amenazas (*Threat Hunting*), el uso de inteligencia sobre amenazas (*Threat Intelligence*), el análisis de indicadores de compromiso (IoC) e indicadores de ataque (IoA), así como el proceso de triaje y las actividades posteriores a un incidente.

También se exploran herramientas ampliamente utilizadas por los analistas SOC, como **VirusTotal**, además de conceptos relacionados con la documentación de incidentes, la continuidad del negocio y la mejora continua del proceso de respuesta.

Este módulo desarrolla competencias fundamentales para los roles de **SOC Analyst**, **Blue Team**, **Incident Responder** y **Threat Hunter**.

---

# Objetivos de aprendizaje

Al finalizar este módulo serás capaz de:

- Comprender los diferentes métodos de detección de incidentes.
- Explicar el funcionamiento del Threat Hunting.
- Diferenciar entre Threat Hunting y Threat Intelligence.
- Comprender el uso de plataformas TIP.
- Identificar Indicadores de Compromiso (IoC).
- Diferenciar IoC e IoA.
- Interpretar la Pirámide del Dolor.
- Analizar indicadores utilizando VirusTotal.
- Comprender el valor del Crowdsourcing y OSINT.
- Aplicar buenas prácticas de documentación.
- Comprender el proceso de triaje de incidentes.
- Explicar la importancia de la continuidad del negocio.
- Comprender las fases posteriores a un incidente.
- Elaborar documentación útil para investigaciones de seguridad.

# Conclusión

La detección temprana y una respuesta organizada son elementos fundamentales de cualquier programa de ciberseguridad. En este módulo se presentan las metodologías, herramientas y procesos que utilizan los equipos de seguridad para identificar amenazas, investigar incidentes y mejorar continuamente su capacidad de respuesta.

Los conocimientos adquiridos aquí constituyen una base esencial para desempeñar funciones en un Centro de Operaciones de Seguridad (SOC) y sirven como preparación para módulos posteriores enfocados en el análisis y la respuesta ante amenazas más avanzadas.
