# Laboratorios del Módulo 4

## Descripción

Esta carpeta contiene los laboratorios realizados durante el **Módulo 4** del curso **Google Cybersecurity Professional Certificate**.

En este módulo se trabaja con **Suricata**, una herramienta de código abierto utilizada para la detección y el monitoreo de amenazas en redes. Los laboratorios permiten poner en práctica los conceptos estudiados sobre reglas de detección, análisis de tráfico y revisión de registros generados por la herramienta.

> **Nota:** Los laboratorios incluidos en esta carpeta corresponden a prácticas oficiales del curso.

---

# 🎯 Objetivos

Al completar los laboratorios de este módulo podrás:

- Comprender el funcionamiento básico de Suricata.
- Ejecutar Suricata sobre un archivo de captura de red (PCAP).
- Crear y utilizar reglas de detección.
- Analizar las alertas generadas por Suricata.
- Interpretar la información almacenada en los archivos de registro.
- Familiarizarte con el uso de **jq** para inspeccionar archivos JSON.

# 🎯 Conclusión

Los laboratorios de este módulo complementan la teoría mediante ejercicios prácticos con Suricata.
