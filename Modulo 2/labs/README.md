# Laboratorios del Módulo 2

## Descripción

Esta carpeta contiene los laboratorios prácticos desarrollados durante el estudio del **Módulo 2: Comprender el tráfico de red y la captura de paquetes** del Certificado Profesional de Google Cybersecurity.

El objetivo de estos ejercicios es complementar la teoría mediante actividades prácticas enfocadas en el análisis de tráfico de red utilizando herramientas ampliamente empleadas en la industria, como **tcpdump** y **Wireshark**.

Cada laboratorio incluye instrucciones paso a paso, comandos utilizados, explicaciones y conclusiones para reforzar los conceptos estudiados.

---

# Objetivos

Al completar estos laboratorios podrás:

- Capturar tráfico de red utilizando `tcpdump`.
- Aplicar filtros para reducir el volumen de información analizada.
- Guardar capturas en formato PCAP.
- Abrir y analizar archivos PCAP con Wireshark.
- Identificar protocolos, direcciones IP y puertos.
- Desarrollar habilidades básicas para el análisis de tráfico durante una investigación de ciberseguridad.

---

# Contenido

## Lab-01-Captura-con-tcpdump.md

Introducción al uso de `tcpdump` para capturar tráfico de red desde una interfaz.

Temas:

- Identificación de interfaces
- Captura básica
- Visualización de paquetes
- Finalización de la captura

---

## Lab-02-Filtros-de-tcpdump.md

Uso de filtros para capturar únicamente el tráfico relevante.

Temas:

- Filtros por IP
- Filtros por puerto
- TCP
- UDP
- ICMP
- Combinación de filtros

---

## Lab-03-Analisis-en-Wireshark.md

Análisis de una captura utilizando Wireshark.

Temas:

- Apertura de archivos PCAP
- Filtros de visualización
- Interpretación de protocolos
- Seguimiento de conversaciones

---

## Lab-04-Investigacion-de-un-PCAP.md

Pequeño ejercicio de investigación simulando el análisis inicial de un incidente.

Temas:

- Identificación del tráfico
- Protocolos involucrados
- Comunicación entre equipos
- Observaciones del análisis

---

# Requisitos

Para realizar estos laboratorios se recomienda contar con:

- Linux (Ubuntu o Kali Linux)
- tcpdump
- Wireshark
- Permisos de administrador (sudo)
- Conocimientos básicos de redes TCP/IP

---

# Buenas prácticas

- Trabajar en un entorno controlado o de laboratorio.
- Capturar únicamente el tráfico necesario.
- Proteger los archivos PCAP generados.
- Documentar las observaciones realizadas durante cada práctica.
- No capturar tráfico de redes o sistemas sin autorización.

---

# Nota

Estos laboratorios tienen un propósito exclusivamente educativo y están diseñados para reforzar los conocimientos adquiridos durante el curso. Cualquier actividad de captura o análisis de tráfico debe realizarse respetando las políticas de seguridad y la legislación aplicable.
