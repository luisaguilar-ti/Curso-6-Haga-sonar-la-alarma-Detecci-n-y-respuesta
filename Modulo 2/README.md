# Módulo 2 - Tráfico de Red y Análisis de Paquetes

## Introducción

El tráfico de red representa el flujo constante de datos entre dispositivos conectados a una red. Comprender cómo viaja esta información y cómo analizarla es una habilidad fundamental para cualquier analista de ciberseguridad.

En este módulo aprenderás a interpretar el funcionamiento de las comunicaciones de red, identificar la estructura de los paquetes y utilizar herramientas de análisis para detectar actividades sospechosas. También conocerás conceptos esenciales como direcciones IP, protocolos de red y captura de paquetes.

Estos conocimientos servirán como base para el análisis de registros (logs), la investigación de incidentes y el uso de herramientas SIEM en los módulos posteriores.

---

## Objetivos de aprendizaje

Al finalizar este módulo serás capaz de:

- Comprender qué es el tráfico de red.
- Identificar los componentes de un paquete de datos.
- Explicar el funcionamiento básico del protocolo IP.
- Analizar capturas de red mediante herramientas especializadas.
- Utilizar `tcpdump` para capturar y filtrar tráfico.
- Comprender el papel de Wireshark en una investigación de seguridad.
