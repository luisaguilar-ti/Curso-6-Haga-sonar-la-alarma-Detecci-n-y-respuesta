# Módulo 2: Monitoreo y Análisis del Tráfico de Red

## Descripción

En este módulo se estudian los fundamentos del monitoreo y análisis del tráfico de red. Se aprende cómo viajan los datos a través de una red, cómo interpretar la información contenida en los paquetes y cómo utilizar herramientas de análisis como **tcpdump** y **Wireshark** para investigar eventos e incidentes de seguridad.

---

# Objetivos

Al finalizar este módulo serás capaz de:

- Comprender qué es el tráfico de red.
- Explicar cómo se transmiten los datos mediante paquetes.
- Identificar la información contenida en un paquete de red.
- Interpretar los campos más importantes del encabezado IPv4.
- Capturar tráfico utilizando tcpdump.
- Analizar capturas de red con Wireshark.
- Investigar comunicaciones sospechosas mediante el análisis de paquetes.
