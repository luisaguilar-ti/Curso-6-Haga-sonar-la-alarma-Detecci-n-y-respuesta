# Módulo 1: Fundamentos de la Detección y Respuesta

## Descripción

En este módulo se presentan los conceptos fundamentales de la detección y respuesta a incidentes de ciberseguridad. Se estudia el funcionamiento de un Centro de Operaciones de Seguridad (SOC), las principales herramientas utilizadas por los analistas de seguridad y el ciclo de vida de respuesta a incidentes propuesto por el NIST.

---

# Objetivos

Al finalizar este módulo serás capaz de:

- Comprender qué es un incidente de seguridad.
- Explicar cómo trabaja un SOC.
- Comprender el funcionamiento de un SIEM.
- Comprender el funcionamiento de un SOAR.
- Diferenciar IDS, IPS y EDR.
- Explicar el ciclo de respuesta a incidentes del NIST.
